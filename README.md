# Softixer Code

Your AI-powered coding assistant, right in your editor — powered by [Softixer](https://softixer.com).

## What Can Softixer Code Do For You?

- **Generate Code** from natural language descriptions
- **Refactor & Debug** existing code
- **Write & Update** documentation
- **Answer Questions** about your codebase
- **Automate** repetitive tasks
- **Utilize MCP Servers** for extended capabilities

## Modes

Softixer Code adapts to how you work:

- **Code Mode** — everyday coding, edits, and file ops
- **Architect Mode** — plan systems, specs, and migrations
- **Ask Mode** — fast answers, explanations, and docs
- **Debug Mode** — trace issues, add logs, isolate root causes
- **Custom Modes** — build specialized modes for your team or workflow

## Getting Started

1. Install the extension
2. Get your API key from [softixer.com/pricing](https://softixer.com/pricing)
3. Enter your API key in the settings
4. Start coding with AI!
